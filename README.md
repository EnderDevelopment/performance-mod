# Performance Mod

Optimize your Minecraft 1.8.9 experience with this powerful performance mod.

## Features

- Smart render distance
- Entity culling
- Particle limiter
- Clean ClickGUI with categories (Performance, Visuals, HUD, Misc)
- Readable HUD (FPS, coordinates, potion effects, armor)
- Custom main menu with black to red gradient
- Keybinds
- Setting profiles
- Zoom
- Better tab list
- Smooth chat

## Requirements

- Minecraft 1.8.9
- Forge 1.8.9

## Installation

1. Download the latest release from the [Releases](https://github.com/EnderDevelopment/performance-mod/releases) page.
2. Place the downloaded JAR file in your Minecraft `mods` folder.
3. Launch Minecraft with the Forge profile.

## Usage

1. Launch Minecraft with the Forge profile.
2. Press the designated key (default: Right Shift) to open the ClickGUI.
3. Customize the mod settings to your liking.

## Configuration

The mod includes a configuration file located at `config/barclient.cfg`. You can edit this file to customize the mod settings.
